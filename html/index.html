Ejercicios con Prompt en JavaScript

1. Comparador de Letras: Comparar dos letras y determinar si la primera está antes o después según el abecedario.

2. Área de un Triángulo: Calcular el área de un triángulo pidiendo al usuario el ingreso de la base y de la altura.

3. Analizador de Ciudades: Solicitar ciudad y país, concatenarlos separados por coma y espacio, y comparar la longitud.

4. Reemplazo de Interrogaciones: Ingresar cadena impar intercalando dígitos y '?' para reemplazar por la suma de adyacentes.
